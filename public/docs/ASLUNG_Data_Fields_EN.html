3. Cleaned, calibrated and final values

Here * represents a full PM channel name, such as PM1_G3, PM2.5_G3 or PM10_GSA. G3 and GSA are processed separately. A channel without an applicable coefficient may have a cleaned value but no calibrated or final value.

Field / codeDescription
PM1_G3 / PM2.5_G3 / PM10_GSAExample raw PM fields, preserved without replacement.
*_cleanAfter PM anomaly and Ghost Peak cleaning, before coefficient calibration.
*_calibratedApplicable measurement-time coefficient applied to the cleaned value: a × x + b. In six-rule mode, non-finite or negative results are blank.
*_finalAfter the PM1 cap and rule 6 exclusion. Usually the PM analysis value; also inspect quality flags.
temperature_clean / rh_clean / co2_cleanCleaned under rule 3; values below 1 or invalid values are blank. No PM calibration coefficient is applied to these fields.

Reading example

PM1_G3 = 12
PM1_G3_clean = 12
PM1_G3_calibrated = 18
PM1_G3_final = 15

If the corresponding calibrated PM2.5 is 15 and no other exclusion applies, final PM1 is capped to 15. Raw 12 and calibrated 18 remain available.

5. Six processing rules

  1. Exclude all three PM channels when equal and > 50; exclude individual PM values below 1.
  2. Ghost Peak uses PM2.5, five passes in each direction and the valid values among the preceding five samples. A ratio < 10 is retained. If neither direction retains the sample, all three PM channels in the group are excluded. It is not a single ten-times-average test.
  3. Cleaned temperature, humidity and CO₂ are blank for invalid values or values below 1; raw fields are retained.
  4. Select coefficients by device, channel and measurement time. Segment 1 uses x < break_point1; equality uses segment 2. Without segment 2, use segment 1 throughout. Non-finite or negative calibrated results are blank.
  5. If valid calibrated PM1 > PM2.5 in the same group, cap final PM1 to PM2.5.
  6. Using the three raw PM values: if rawPM1 > 50 and |rawPM1 − (rawPM1 + rawPM2.5 + rawPM10) / 3| ≤ up_limit, all three final PM values are blank. Default up_limit: 3.

Cleaning excludes derived values without deleting original measurement rows. PM125 and UNMAPPED coefficient channels are lookup-only. Factor_* columns are not used in calculation.

7. Time, filenames and historical results

  • Exported timestamps use UTC. For example, 2026-09-30T16:00:00.000Z is 2026-10-01 00:00:00 in Taiwan. Enter query times in the timezone selected in the app.
  • Daily jobs use [start,end), excluding the end instant; data queries include the end instant. A query ending exactly at next-day midnight also includes that instant and may require the next day’s result.
  • Download names use Taiwan dates, such as AL-1143_20261001.zip or AL-1143_20261001_20261031.zip. ZIP contains CSV or JSON; CSV uses UTF-8 with BOM.
  • A selected period for one device can be merged into one data file. Batch downloads share one ZIP; daily downloads are not required. Multiple authorized segments for the same device retain segment IDs to avoid filename collisions.
  • New jobs with rawSchema=all-fields-1 retain full raw fields. Old results are not backfilled automatically. Ask an administrator to queue a new revision for full fields or corrected processing. When schemas are mixed, unavailable old-file fields are blank.
  • Automatic scheduling processes the last three completed days. Older unprocessed data requires a manually queued job. Inspect quality and versions before analysis.
